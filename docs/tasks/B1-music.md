# 작업 카드 B1: 배경음악 6곡 (코드로 합성)

음악 생성 AI나 외부 음원은 쓰지 않아요. 파이썬 코드로 음을 직접 합성해서 만들어요(네트워크 금지, 새 패키지 설치 금지. `numpy`와 표준 라이브러리 `wave`만 써요).

## 만들 것
- `tools/music/codex_tracks.py`: 실행하면 아래 6곡을 `art/music-src/codex/<이름>.wav`로 써요(44100Hz, 16비트, 스테레오).
- 실행: `python tools/music/codex_tracks.py` (저장소 맨 위에서). 직접 실행해서 파일이 생기는지 확인해요.
- 다른 파일은 고치지 않아요. git commit·reset·push는 하지 않아요.

## 6곡
| 이름 | 쓰이는 곳 | 빠르기 | 분위기 |
|---|---|---|---|
| title | 시작 화면·도감 | 76 BPM | 신비롭고 평온한 판타지. 하프·종 같은 음색 |
| prepare | 석판 돌리기·배치 | 88 BPM | 차분하고 가벼움. 생각하기 좋은 반복 |
| battle_calm | 약한 웨이브 전투 | 100 BPM | 느긋한 행진. 긴장은 낮게 |
| battle_rush | 적 무리가 더 나타났을 때 | 138 BPM | 빨라지고 급박함. 북 소리가 촘촘 |
| boss | 보스전 | 156 BPM | 어둡고 긴박. 단조, 낮은 베이스 반복 |
| final_boss | 마지막 보스 | 168 BPM | 웅장하고 절박. 가장 두껍게 |

## 조건
- 곡마다 40~64초, 마디 수를 딱 맞춰서 **끝과 처음이 끊김 없이 이어지게**(끝에서 소리가 잘리거나 여운이 남아 튀지 않게, 잔향 꼬리는 처음으로 접어 넣기).
- 멜로디·화음·베이스·타악 최소 네 성부. 사인파 하나짜리 삐 소리는 안 돼요. 엔벨로프(ADSR), 배음, 가벼운 잔향이나 딜레이로 듣기 편하게.
- 같은 조성 계열(예: 라단조·파장조 근처)로 맞춰서 곡을 바꿔 틀어도 어색하지 않게.
- 완전 창작 선율. 기존 게임·영화 음악의 선율을 따라 하지 않아요.
- 클리핑 금지: 최대 진폭 -3dBFS 이하, 곡 사이 음량(RMS) 차이는 3dB 안쪽.
- 난수는 고정 시드(다시 돌려도 같은 파일).
