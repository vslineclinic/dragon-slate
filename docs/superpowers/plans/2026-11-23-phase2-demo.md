# 2단계 데모 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 스팀에 올릴 무료 데모(10웨이브 + 재앙 1단계)를 만들고, Windows 실행 파일로 포장하고, 상점 페이지 자료 초안을 준비한다.

**Architecture:** 재앙 단계는 core에 데이터 주도 수정치(`CalamitySpec`)로 넣고 `createRun(data, seed, calamity)`로 받는다. 데모는 빌드 시 `VITE_DEMO=1`로 데이터를 덮어쓴다(maxWave 10, 재앙 최대 1). 처음 하는 사람 안내는 view의 단계별 말풍선. 데스크톱 포장은 Electron(`apps/desktop`), 상점 자료는 `docs/store/`. 코덱스는 Electron 포장(X5)과 상점 자료·캡슐 아트 초안(X6)을 맡는다.

**Spec:** `docs/superpowers/specs/2026-11-23-wyrmslot-design.md` (6.6, 6.7, 9장 2단계, 11장)

## Global Constraints
- 0·1단계 Global Constraints 그대로.
- 재앙은 누적식: n단계를 고르면 1..n의 수정치가 모두 적용. 데이터 `data/calamity.json`.
- 데모: `maxWave` 10, 재앙 최대 1단계, 끝나면 "정식판 안내" 화면. 정식판과 같은 코드, 빌드 설정만 다름.
- 스팀 계정·결제·세금 정보 입력은 사용자가 직접 한다(대신 하지 않음).
- AI 생성 그림을 쓴 사실을 상점 문구에 정직하게 적는다.

## Review Focus
1. 재앙 0단계 결과가 지금과 완전히 같아야 함(기존 리플레이·밸런스 보존) → D1 테스트 `calamity 0 changes nothing`
2. 데모 빌드에서 10웨이브 클리어 시 '승리'가 아니라 데모 종료 안내가 나와야 함 → D2 확인
3. 안내 말풍선이 두 번째 판부터는 안 나와야 함, 언제든 건너뛰기 가능 → D3 확인
4. Electron 창 크기 변경·전체화면에서 레터박스 유지 → X5 확인
5. 재앙 단계 해금이 판을 깬 단계 기준으로만 열림(진 판으로 열리지 않음) → D1/D2 테스트 `unlock only on victory`

### D1: 재앙 단계 (Claude)
- `CalamitySpec { level: number; nameKo: string; descKo: string; enemyPowerPct?: number; bossPowerPct?: number; winManaPct?: number; rerollCostAdd?: number; startLivesAdd?: number }`, `GameData.calamity`, `RunState.calamity`.
- `createRun(data, seed, calamity = 0)`; `calamityMods(data, level)`로 1..level 합산. 적 전투력 ×(100+enemyPowerPct)/100, 보스 웨이브는 추가로 bossPowerPct, 승리 마력 ×(100+winManaPct)/100(내림), 다시 돌리기 비용 +rerollCostAdd(0원 첫 스핀 제외), 시작 생명 +startLivesAdd(최소 1).
- 1~5단계: 1 적 +15% / 2 승리 마력 −20%, 다시 돌리기 +1 / 3 보스 +25% / 4 적 +15% / 5 시작 생명 −1.
- 테스트: `calamity 0 changes nothing`, `level 1 raises enemy power 15%`, `levels stack`, `reroll cost add skips free first spin`, `start lives never below 1`.

### D2: 데모 모드·해금 (Claude)
- `packages/view/src/build.ts`: `IS_DEMO = import.meta.env.VITE_DEMO === '1'`; 데모면 데이터 maxWave 10, 재앙 최대 1.
- 재앙 해금 저장(`wyrmslot.calamity.unlocked`, localStorage): 승리한 판의 단계+1까지 열림. 시작 화면에 재앙 단계 고르기(◀ n ▶, 이름·설명).
- 데모에서 마지막 웨이브를 깨면 결과 화면 대신 "데모 클리어! 정식판에서는 20웨이브·심판 보스 4종·재앙 5단계" + [처음으로].
- npm 스크립트 `build:demo` = `VITE_DEMO=1 vite build --outDir ../../dist-demo` (Windows에서도 동작하게 `cross-env` 없이 vite `--mode demo` + `.env.demo` 사용).
- 확인: 데모 빌드 미리보기에서 10웨이브 표시, 재앙 선택 최대 1.

### D3: 처음 하는 사람 안내 (Claude)
- `packages/view/src/panels/Tutorial.ts`: 첫 판(저장 `wyrmslot.tutorial.done` 없음)에서 단계별 말풍선 1개씩: ① 돌리기 버튼 ② 보라 띠 줄·카드 고르기 ③ 끌어서 합치기/둥지에 놓기 ④ 전투 시작 ⑤ 보스 예보. 각 말풍선은 해당 행동을 하면 다음으로, [건너뛰기]로 전체 종료.
- 확인: 첫 판에만 나오고, 건너뛰기 동작.

### X5: 데스크톱 포장 (Codex 카드)
- `apps/desktop/main.cjs`(Electron 메인): `dist/` 의 index.html을 띄움, 창 1280×720 최소 960×540, 메뉴 없음, F11 전체화면, 외부 링크는 기본 브라우저로.
- 스크립트: `desktop` (= build 후 electron 실행), `desktop:pack` (electron-builder로 Windows portable exe, 출력 `release/`). 의존성(electron, electron-builder)은 지휘자가 미리 설치.
- 스팀 연동은 이번 범위 밖(앱 ID가 생긴 뒤).

### X6: 상점 페이지 자료 초안 (Codex 카드)
- `docs/store/store-page.md`: 한국어·영어 짧은 설명(300자 이내), 긴 설명, 특징 5개, 추천 태그 20개, 최소 사양, AI 사용 공시 문구(그림·문구에 생성형 AI 사용, 코드도 AI 도움), 스크린샷 촬영 목록 6장, 트레일러 30초 구성안.
- `art/store/` 캡슐 아트 초안(image_gen): header 920×430, small 462×174, main 1232×706, library 600×900. 기존 드래곤 그림과 같은 화풍, 제목 글자는 넣지 말 것(글자는 나중에 합성).
