# 0단계 재미 검증 시험 안내

## 시험 방법
- 시험 빌드를 열고 **한 판 이상**(10웨이브 또는 게임 오버까지) 해요. 설명은 최소로 하고, 막혀도 바로 도와주지 말고 관찰해요.
- 시험이 끝나면 아래 질문 5개를 물어요. 답은 그대로 받아 적어요.
- **가장 중요한 관찰:** 판이 끝난 뒤 시키지 않았는데 "한 판 더"를 누르거나 말하는지.

## 질문 5개
1. 가장 재밌던 순간은 언제였나요?
2. 지루하거나 답답했던 순간은요?
3. 한 판 더 하고 싶었나요? 왜요?
4. 이해가 안 된 규칙이 있었나요?
5. 다음 판에 해 보고 싶은 조합이나 시도가 있나요?

## 통과 기준
- 5명 중 **3명 이상**이 시키지 않아도 한 판 더 → 1단계(핵심 완성)로 진행
- 2명 이하 → 답답했던 순간·모르겠던 규칙을 모아 핵심 규칙(석판·조합·전투)부터 다시 손봐요

## 밸런스 기준값 (봇 10,000판, 2026-11-23)
| 지표 | 값 | 목표 |
|---|---|---|
| 클리어율 | 42.1% | 30~60% |
| 5웨이브 끝날 때 2티어 이상 보유 | 100% | 90% 이상 |
| 합치기 중 흡수 비율 | 8.1% | 흡수가 대부분이면 실패 |
| 첫 웨이브 승률(새 드래곤 2마리) | 97% | 첫 판 첫 전투에서 지지 않게 |
| 스핀당 줄 맞춤(밀기 전 → 후) | 63% → 96% | — |

봇이 이중원소룡과 티아마트를 거의 매판 최종 둥지에 넣어요(이중원소 각 77~79%, 티아마트 38%). 1티어는 잘 안 쓰여요(베이시르만 6%). 시험에서 사람도 그렇게 하는지 봐 두면, 1단계 밸런스의 근거가 돼요.
