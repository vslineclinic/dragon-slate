# 스팀 데모 출시까지 직접 하셔야 하는 일

계정·결제·세금·법적 동의가 필요한 일이라 대신할 수 없는 것들이에요. 순서대로 하시면 돼요.

## 1. Steamworks 가입과 앱 등록
1. https://partner.steamgames.com 에서 Steamworks 파트너 가입(본인 확인, 은행 계좌, 세금 정보).
2. Steam Direct 등록비 100달러 결제 → 앱 ID 2개 받기(본편 + 데모). 데모 앱은 본편 앱 안에서 "데모 만들기"로 추가해요.
3. 결제 후 최소 30일이 지나야 출시할 수 있고, 상점 페이지는 출시 2주 전부터 공개돼 있어야 해요. 그러니 **가입은 빨리** 하는 게 좋아요.

## 2. 상점 페이지 채우기
- 문구: `docs/store/store-page.md`의 한국어·영어 초안을 복사해서 다듬어 넣어요. 태그는 스팀 공식 목록과 맞는지 확인하세요.
- 캡슐 아트: `art/store/` 초안 4장(header·small·main·library)에 제목 로고를 합성해야 해요. 외주를 맡기실 거면 이 초안을 참고 자료로 보내면 돼요.
- 스크린샷: 문서의 촬영 목록 6장. 게임을 1280×720 이상으로 띄운 뒤 `Win+Shift+S`로 찍으면 돼요.
- **AI 사용 공시**: 상점 설정의 "AI 생성 콘텐츠" 항목에 문서의 공시 문구를 넣어요. 문구에 "개발자가 결과물을 고르고 검토했습니다"가 있으니 실제로 그렇게 하셨는지 확인하고, 아니면 그 문장을 고쳐 주세요.

## 3. 데모 빌드 올리기
- 데모 실행 파일: `npm run desktop:pack:demo` → `release-demo/` (스팀에 올릴 때는 `release-demo/win-unpacked/` 폴더를 써요). 본편은 `npm run desktop:pack` → `release/`.
- 업로드는 Steamworks SDK의 SteamPipe(ContentBuilder)로 해요. 앱 ID가 생기면 업로드 설정 파일을 만들어 드릴게요.

## 4. 넥스트 페스트
- 보통 2월·6월·10월에 열리고, 신청 마감이 몇 주 전이에요. Steamworks의 "Steam Next Fest" 페이지에서 날짜를 확인하고 신청하세요.
- 신청 전 데모가 스팀 검토를 통과해 있어야 해요.

## 5. 한국 등급분류
- 스팀에 한국어로 내려면 등급분류가 필요해요. 게임물관리위원회 기준과 자체등급분류 경로를 출시 전에 확인하세요(설계 문서 11장 참고).

## 6. 홍보 (개발 일지)
- `docs/devlog/`의 기록이 유튜브·스레드 글감이에요. 상점 페이지가 열리면 위시리스트 링크를 걸어요.
