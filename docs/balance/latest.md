# 밸런스 측정 (2026-11-26, 1지역 「잊힌 평원」)

명령: `npm run sim -- --runs 50 --seed <1000|2000|3000|4000> --stage 1 --start` 네 묶음, 합쳐 200판. 봇은 시작 묶음을 고르고 20웨이브를 해요.

이 파일의 예전 내용(2026-11-23, 40웨이브 한 판 · 옛 종 이름)은 지역 구조가 생기기 전 측정이라 지웠어요. git 기록에 남아 있어요.

## 바꾼 것

외부 검토(제미나이)와 내부 상용화 검토가 같은 문제를 짚었어요. 10웨이브까지는 거의 지지 않고, 지는 판은 20웨이브 보스에 몰려요. 클리어율 목표(지역마다 약 15%)는 그대로 두고 어려운 곳을 앞으로 옮겼어요.

| `data/stages.json` 1지역 | 전 | 후 |
|---|---|---|
| 성장률 9~14웨이브 | 120% | 123% |
| 성장률 15~20웨이브 | 118% | 117% |
| 10웨이브 보스 배율 | 122% | 135% |
| 15웨이브 보스 배율 | 120% | 110% |
| 20웨이브 보스 배율 | 118% | 112% |

## 남은 것

- 2~4지역은 아직 다시 재지 않았어요(`--stage N --start --carry <종id>`).
- 밀기 뒤 줄 맞춤 비율(예전 측정 96%)은 이번 봇 출력에 없어서 확인하지 못했어요.
- 봇 수치예요. 사람이 느끼는 어려움은 직접 해 봐야 알아요.

## 1지역을 10웨이브로 (2026-11-26, 사용자 제안)

1지역 「잊힌 평원」은 익히는 곳이라 10웨이브(보스 5 · 10)로 줄였어요. 둥지 칸은 2 · 4 · 7웨이브 뒤에 열려요. 데모판도 이제 1지역과 같아요.
클리어율 목표는 다른 지역(약 15%)과 달리 **약 70~80%**로 잡았어요(익히는 곳이라 대부분 깨되 10웨이브 보스는 긴장되게). 이 목표는 Claude가 제안했고 사용자가 승인했어요(2026-11-26).

| 시도 | 성장률(2웨이브~) | 5 · 10웨이브 보스 | 클리어율 | 10웨이브 보스 첫 도전 |
|---|---|---|---|---|
| 처음 | 125% | 110 · 115 | 100% | 99% |
| A (100판) | 127% | 110 · 150 | 92% | 70% |
| B (100판) | 129% | 120 · 170 | 58% | 31% |
| **채택 (200판)** | 128% | 115 · 160 | **77%** | 49% |

2~4지역은 바꾸지 않았어요. 1지역에서 데려가는 드래곤은 원래 레벨 1로 가니 2지역 시작 조건은 같아요.
